> Official web application and landing page for **ONER**, a high-performance sports brand specialized in professional goalkeeper equipment, entirely conceived, designed, and developed by me.

---

## 📌 About the Project

**ONER** is a professional equipment brand concept built around a minimalist **Dark Tech** visual identity. This project serves as the official web presentation for the brand, highlighting its manifesto, design philosophy, and technical product line.

It demonstrates a complete end-to-end product creation workflow — spanning brand concept, UI/UX design, visual hierarchy, and clean front-end implementation.

---

## ✨ Key Features

- **Dark Tech Aesthetic:** High-contrast layout with dark backgrounds, sharp contrast, and high-visibility neon green accents.
- **UI/UX & Visual Hierarchy:** Immersive typography and clean layout structured to emphasize brand value and product specifications.
- **Responsive Design:** Fully responsive layout built to ensure seamless experience across mobile, tablet, and desktop devices.
- **Brand Manifesto:** Dedicated, structured presentation of the brand's core purpose and positioning.
- **Product Showcase:** Modular layout designed for technical goalkeeper gear and glove displays.

---

## 🛠️ Tech Stack & Concepts

- **Front-End:** HTML5, CSS3, JavaScript
- **Design & Strategy:** UI/UX Design, Product Strategy, Brand Identity, Responsive Layouts
- **Version Control:** Git, GitHub
